OPENBCI GANGLION · SIGNAL VALIDATION

어디까지 정상인지, 한 단계씩.

전송 → 전극·잡음 → 알파 반응 → 화면 → 단일 SSVEP → 분류

아침 실험 안내서 열기 · 모든 기록은 이 컴퓨터에 저장됩니다.

먼저 깜빡임 없이 수집과 전극을 확인하세요. 광과민성 발작 병력이 있거나 깜빡임으로 이상 증상이 생기면 자극 실험을 진행하지 마세요. 불편·어지러움·두통이 생기면 즉시 Esc로 중단하세요. 보드는 배터리로만 사용합니다.

기존 녹화 감사 · 합성 정상·실패 예제 · 공개 EEG 참고 예제

1. GUI → LSL 연결

GUI: Ganglion (live), Networking → LSL / TimeSeries / EEG / Filters Off.

GUI 녹화와 이 앱 녹화를 함께 사용하세요. GUI의 FFT/BandPower 출력은 입력으로 쓰지 않습니다.

2. 오늘의 배치 기록

분석할 채널: 처음에는 접촉이 좋은 1채널부터.

아직 세션이 없습니다.

설정이나 전극을 바꾸면 새 세션을 만드세요. 서로 다른 배치를 같은 비교에 섞지 않습니다.

3. 실시간 품질

최근 10초. 자극 중에는 화면 갱신을 멈춥니다. 자동 기준 통과는 뇌파 검출의 증명이 아닙니다.

연결 후 실시간 보기를 켜세요.

4. 단계별 실험

① 30초 수집② 눈·턱 아티팩트③ 알파 3쌍④ 화면 검사⑤ 단일 자극 + 기준선⑥ 3지선다 + 시선 이탈

시간축·품질에 문제가 있으면 해당 단계에서 원인을 찾으세요. 알파가 약하다는 이유만으로 장비 고장을 판정하지 않습니다.

눈 감기 전 음성이 들리는지 확인하세요. 혼자 할 때는 음성 안내를 켜세요.

대기

아직 깜빡임이 없습니다.

Esc: 즉시 중단대기
+

브라우저 프레임 시각은 실제 광출력 시각이 아닙니다. 정밀 확인에는 포토다이오드가 필요합니다.

5. GUI 녹화 파일 검사 (LSL 없이도 가능)

기본 폴더의 파일을 읽습니다. 파일 전체가 같은 조건인 눈 뜸/감음 기록은 쌍으로 비교할 수 있습니다. 과거 파일의 눈 상태를 모르면 ‘조건 모름’으로 검사만 하세요.

조건 비교에는 전환 동작을 제외하고 안정된 상태로 별도 녹화한 20~30초 파일을 사용하세요. 과거 파일은 당시 전극·단위를 확인하고 별도 세션에 추가하세요.
