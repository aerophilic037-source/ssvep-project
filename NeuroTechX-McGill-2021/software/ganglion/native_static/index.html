3. 실시간 품질

최근 10초. 자극 중에는 화면 갱신을 멈춥니다. 자동 기준 통과는 뇌파 검출의 증명이 아닙니다.

연결 후 실시간 보기를 켜세요.

개인 학습 실험 · eTRCA / eCCA

개인 학습 화면 열기 · 12/15 Hz 보정 후 모델을 고정하여 독립 평가합니다.

각 단계: 12 Hz 15회 + 15 Hz 15회 + 시선 이탈 15회. 한 번에 최대 15회 진행 후 휴식합니다. 6초 자극·5초 준비, 분석은 시작 후 1~5초입니다. 소프트웨어 시계 정렬은 광출력 동기화 검증이 아닙니다.

위 정지 사각형 한 변을 자로 재세요. 자극은 150 CSS px 사각형입니다. 실측 크기를 기록하세요. 전극 위치와 REF/D_G를 입력해 새 세션을 만들고, 화면 검사와 자극 확인을 완료하세요. 보정·평가 사이에 배치나 화면 크기를 바꾸면 새 세션이 필요합니다.

평가의 보류·중단·품질 실패는 정답률 분모에 남습니다. 보정 실패는 기록을 보존하고 같은 슬롯에서 다시 수집합니다.

처음 시작한다면 복구는 건너뛰세요. 위 배치 기록에 실제 REF/D_G 위치를 입력하고 설정 저장 · 새 세션 만들기를 누르세요.

이전에 진행한 개인 실험 이어서 하기 (처음에는 사용하지 않음)

숫자 1이 아니라 저장된 전체 세션 ID를 입력합니다. 개인 실험을 준비한 적이 있는 세션만 복구할 수 있습니다.

추가 선택 정확도 실험 · 최대 20개

추가 실험 화면 열기 · 기존 단계별 실험으로

목표를 먼저 정하고 안내된 자극을 바라보세요. 클릭은 정답 지정이며 EEG 예측과 별개입니다. 20개는 탐색 구성으로 성능이 검증되지 않았습니다.

설정 저장으로 새 세션을 만든 뒤 아래 화면 검사와 자극 확인을 마치고 ‘선택한 실험 시작’을 누르세요. 결과는 아래에 회차별로 표시됩니다.

4. 단계별 실험

① 30초 수집② 눈·턱 아티팩트③ 알파 3쌍④ 화면 검사⑤ 단일 자극 + 기준선⑥ 3지선다 + 시선 이탈

시간축·품질에 문제가 있으면 해당 단계에서 원인을 찾으세요. 알파가 약하다는 이유만으로 장비 고장을 판정하지 않습니다.

눈 감기 전 음성이 들리는지 확인하세요. 혼자 할 때는 음성 안내를 켜세요.

처음에는 15 Hz 하나로 시작하세요. 단계를 바꿀 때 새 세션을 만들면 결과를 따로 비교할 수 있습니다.

5. GUI 녹화 파일 검사 (LSL 없이도 가능)

기본 폴더의 파일을 읽습니다. 파일 전체가 같은 조건인 눈 뜸/감음 기록은 쌍으로 비교할 수 있습니다. 과거 파일의 눈 상태를 모르면 ‘조건 모름’으로 검사만 하세요.

조건 비교에는 전환 동작을 제외하고 안정된 상태로 별도 녹화한 20~30초 파일을 사용하세요. 과거 파일은 당시 전극·단위를 확인하고 별도 세션에 추가하세요.
