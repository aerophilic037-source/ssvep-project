OPENBCI · LOCAL EXPERIMENT

Ganglion SSVEP

연결 확인 → 바라볼 자극 선택 → 5초 측정

EEG 품질부터 확인하려면 bash software/ganglion/start_validation.sh 실행 후 단계별 검증 화면을 여세요.

1. EEG 연결

GUI에서 Ganglion → Networking → LSL / TimeSeries / EEG를 켜세요.

2. 사용할 채널과 정답

후두부에 실제 연결한 채널만 선택하세요. CH1은 배열 인덱스 0입니다.

처음에는 A·B·C를 번갈아 선택하고 지정한 자극을 바라보세요. 연결된 전극 위치는 별도로 기록하세요.

3. 자극 측정

대기

자극은 시작 버튼을 눌렀을 때만 깜빡입니다. 탭을 벗어나면 중단됩니다.

결과

아직 측정하지 않았습니다.

CCA 점수는 정답 확률이 아닙니다. 판정 기준은 초기 실험값이며 사용자별 검증이 필요합니다.
